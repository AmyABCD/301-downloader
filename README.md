# 🌟 301 Downloader - Бүх Платформын Медиа Татагч

YouTube, Facebook, Instagram, TikTok болон бусад бүх вэбсайтаас **MP4 видео (1080p, 720p, 4K)** болон **MP3 аудио (320kbps, 192kbps)**-г хүссэн нягтрал, чанарын сонголттойгоор татах бүрэн хэмжээний веб програм.

---

### Арга 1: Нэг товшилтоор асаах (Хамгийн хялбар)
`c:\Users\Khishgee\Desktop\ican` фолдер доторх:
👉 **`run_downloader.bat`** файл дээр хулганы зүүн товчийг хоёр товшоод нээнэ үү.

Энэ нь серверийг асаагаад таны вэб хөтөч (Chrome, Edge г.м)-ийг **`http://127.0.0.1:8000`** хаягаар автоматаар нээх болно.

## 🎯 Үндсэн боломжууд

1. **Олон платформ дэмжинэ**:
   - 🔴 **YouTube**: Урт бичлэгүүд, YouTube Shorts, Music
   - 🔵 **Facebook**: Нийтийн видеонууд, Facebook Watch, Reels
   - 🟣 **Instagram**: Instagram Reels, видео постууд
   - ⚫ **TikTok**: Watermark-гүй цэвэр бичлэгүүд
   - 𝕏 **X (Twitter)**, Vimeo, SoundCloud г.м 1000+ сайт

2. **Нягтралын сонголттой (MP4 Видео)**:
   - **4K Ultra HD (2160p)** / **2K Quad HD (1440p)** (хэрэв тухайн бичлэгт байгаа бол)
   - **Full HD (1080p)** - Зөвлөмж болгох өндөр нягтрал
   - **HD (720p)** - Стандарт HD чанар
   - **SD (480p)** & **Бага (360p)** - Зай хэмнэх нягтралууд
   - **Хамгийн өндөр чанар (Best Auto)** - Автоматаар тухайн сайтын хамгийн дээд чанарыг татна

3. **Аудио чанарын сонголттой (MP3)**:
   - **320 kbps** - Студийн дээд чанар (Extreme HQ)
   - **256 kbps** - Маш сайн чанар
   - **192 kbps** - Стандарт чанар (Зөвлөмж)
   - **128 kbps** - Хэмнэлттэй бага хэмжээтэй файл

4. **FFmpeg нэгтгэл (Muxing & Conversion)**:
   - YouTube-ийн 1080p бичлэгүүд дуу дүрс тусдаа байдаг тул `FFmpeg`-ээр автоматаар нэгтгэж жинхэнэ дуутай `.mp4` файл болгоно.
   - Видеоноос шууд дууг нь ялган салгаж цэвэр `.mp3` файл үүсгэнэ.

5. **Бодит цагийн явцын самбар (Real-time Progress Bar)**:
   - Таталтын явц (0% - 100%)
   - Татаж буй хурд (Speed: жишээ нь `5.4 MB/s`)
   - Үлдсэн хугацаа (ETA: `үлдсэн: 6с`)
   - Боловсруулалтын шатууд ("Серверт татаж байна", "FFmpeg нэгтгэж байна", "Бэлэн боллоо")

6. **Вэб дээр шууд тоглуулах (Inline Player)**:
   - Татсан бичлэг эсвэл дуугаа татаж авахын өмнө/дараа шууд вэб дээрээ сонсож, үзэж болно.

7. **Татаж авсан түүх ба Windows хавтас нээх**:
   - Өмнө нь татсан бүх файлын жагсаалт, хэмжээг харах боломжтой.
   - "Хавтас нээх" товчийг дарахад Windows Explorer шууд нээгдэнэ.

## 🛠 Технологийн стек
- **Backend**: Python 3.13, FastAPI, Uvicorn
- **Таталтын хөдөлгүүр**: `yt-dlp` (хамгийн сүүлийн хувилбар)
- **Хөрвүүлэлт**: `FFmpeg` (`imageio_ffmpeg` сангаар бүрэн автомат холбогдсон)
- **Frontend**: HTML5, Vanilla JavaScript (SSE / Server-Sent Events), Tailwind CSS (Dark Mode), FontAwesome
