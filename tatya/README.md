# Татъя — энгийн MP4 / MP3 татагч

Нэг хуудастай, Монгол хэлтэй сайт. YouTube, Facebook, Instagram-ийн нийтэд нээлттэй нэг бичлэгийг шалгаж, бодитоор олдсон нягтралаас сонгоно. MP3: 128/192/320 kbps. MP4 нягтрал нь сонгосноос хэтрэхгүй, боломжтой хамгийн сайн хувилбар. Дуу болон видеог FFmpeg нэгтгэнэ. MP4 видео дахин encode хийхгүй; бэлэн MP4 татах эсвэл MP4 видео + M4A дууг нэгтгэнэ. MP4 хувилбар олдохгүй бол MP3 сонгож болно. Анхны сонголт 720p хүртэл байна; хүсвэл өндөр нягтрал сонгоно.

## Windows дээр турших
1. Docker Desktop суулгаж ажиллуулна.
2. Энэ ZIP-ийг бүтнээр задлаад хавтас дотроос Terminal нээнэ.
3. `docker build -t tatya .`
4. `docker run --rm -p 8000:8000 tatya`
5. Браузерт http://localhost:8000 нээнэ.

## Бусад хүн ашиглах нийтэд нээлттэй сайт болгох
1. GitHub дээр шинэ repository үүсгээд энэ хавтасны файлуудыг оруулна (Dockerfile үндсэн түвшинд байна).
2. Render.com дээр New > Blueprint сонгоод repository холбоно.
3. render.yaml үнэгүй Free сервер сонгодог. Төлбөртэй багц сонгох шаардлагагүй. 15 минут ашиглаагүй үед сервер унтаж, дараагийн хүсэлтээр асна. Render-ийн асаалтын хүлээлтийг энэ сайтын загвараар арилгахгүй.
4. Deploy дууссаны дараа Render-ийн өгсөн HTTPS линкийг бусдад түгээнэ.

Энэ багц өөрөө нийтлэгдээгүй. Render/GitHub нэвтрэх эрхгүйгээр сервер үүсгэж нийтлэх боломжгүй.

## Хязгаар ба хамгаалалт
- Зэрэг 2 ажил; нэг IP хаягт минутанд 12 API эхлүүлэх хүсэлт. Reverse proxy ашиглавал бодит хэрэглэгчийн IP таних trusted proxy тохиргоог администратор нэмэх шаардлагатай; одоогийн тохиргоо IP header-д итгэдэггүй тул прокситой үед хязгаар нийт хэрэглэгчдэд хамт үйлчилж болно.
- Хүлээлгийн урт дараалал үүсгэхгүй. Завгүй үед ойлгомжтой хариу өгнө.
- Нэг файл 500 MB, бичлэг 2 цаг, таталтын хугацаа 15 минут. Нэгээс олон клиптэй post, playlist, live дэмжихгүй.
- Файл бэлэн болсноос нэг цагийн дараа дараагийн хүсэлтээр устгана. Сервер дахин асвал ажлын мэдээлэл алга болно. Энгийн нэг instance ашиглана; олон worker бүү ажиллуулаарай.
- Docker контейнер устахад татсан файлууд устна. Шинэчлэл бүрт хуучин түр файлуудыг дахин ашиглахгүй.
- Нууц хуудас, cookies оруулах, төлбөртэй/DRM контент тайлах боломжгүй. Cookies, нууц үгийг сервер рүү илгээхгүй.
- Платформууд серверийн IP-ийг хаах эсвэл баталгаажуулалт шаардаж болно. Бүх линкийг татна гэж батлахгүй. Эхлээд зорилтот сервер дээр гурван платформ тус бүрийн зөвшөөрөлтэй нээлттэй бичлэг туршина.
- Платформ өөрчлөгдвөл Docker-ийг cache-гүй дахин build хийнэ: `docker build --no-cache -t tatya .`
- Public үйлчилгээ их ачаалалтай болох үед дискний quota, тусдаа ажлын queue, нийт сүлжээний rate limit, мониторинг нэмнэ.

## Шалгалт
`pip install -r requirements.txt httpx`
`python -m unittest discover -s tests -v`

API болон хуудасны шалгалтад гаднын платформын таталтыг mock ашиглан тусгаарласан. Жинхэнэ YouTube/Facebook/Instagram таталт энэ орчинд баталгаажаагүй. Windows/Docker болон Render дээр ажиллуулж шалгах шаардлагатай.
